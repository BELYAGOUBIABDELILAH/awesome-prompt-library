## Recommended Learning Path

Follow this five-step sequence to build practical prompt engineering skills:

1. **Start with Fundamentals:**  
   [Google Prompting Essentials](https://www.coursera.org/specializations/prompting-essentials-google)  
   Learn the core task, context, references, evaluate, iterate loop for day-to-day work.

2. **Practice Hands-On Structure & Debugging:**  
   [Anthropic Interactive Tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial)  
   Work through nine interactive chapters covering XML tags, system prompts, few-shot examples, and failure-mode debugging.

3. **Learn Developer & API Patterns:**  
   [ChatGPT Prompt Engineering for Developers (DeepLearning.AI)](https://www.deeplearning.ai/courses/chatgpt-prompt-eng)  
   Short, code-first course covering programmatically summarizing, extracting, inferring, and transforming data.

4. **Go Deeper with Engineering Foundations:**  
   *AI Engineering* by Chip Huyen (Chapter 5: Prompt Engineering) & [*The Prompt Report Distilled*](https://arxiv.org/abs/2406.06608)  
   Learn how prompts fit into real-world production architectures, evaluation harnesses, and latency budgets.

5. **Reference Official Documentation Regularly:**  
   Consult the [OpenAI Prompt Engineering Guide](https://platform.openai.com/docs/guides/prompt-engineering) and [Anthropic Prompt Engineering Overview](https://docs.anthropic.com/claude/docs/constructing-a-prompt) whenever building new workflows.

# Privacy Policy

**Last updated: 2026-08-13.** The Open Prompt Library is currently a public, repository-based catalogue. Phase 0 does not collect user accounts, prompt submissions through a hosted form, analytics, cookies, or prompt execution data.

The repository may contain prompt text and source attribution supplied through public contributions. Contributors should not submit personal data, confidential information, credentials, proprietary code, or prompts copied from restricted sources. Source names and redistribution status are recorded for provenance review; unknown or unverified provenance is explicitly labelled and is not presented as verified permission to redistribute.

If future versions add search analytics, hosted forms, accounts, or prompt execution, the project will document what is collected, why it is collected, retention periods, third-party processors, deletion requests, and any change in licensing or redistribution policy before enabling those features. Questions or removal requests should be opened as a GitHub issue without including sensitive information.
